# Changelog

Each release has a section `## <version>`; its text becomes the GitHub release notes and the
Marketplace's "what's new".

## 1.1.0

- The lookups carry the addresses AdGuard Home answered, so a Floorbit with HTTPS naming (#1600)
  can count a seat's HTTPS downloads for the launcher or game it looked up. The agent keeps the
  answers in memory on the event network; Floorbit gets neither them nor who asked.

## 1.0.0

- First release from its own repository. It used to ship with Floorbit and works the same; install
  it from the Marketplace.
